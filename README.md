# «Работа просто» — одностраничник рекрутингового агентства

Логотип — векторная копия присланного клиентом (img/logo-mark.svg, иконка — img/favicon.svg).

Задача: доверие соискателя. Вакансии, как устроен отбор, заявка, ответы на вопросы,
предупреждение о мошенниках, политика конфиденциальности.

## Вакансии

- По умолчанию — из `data.json` рядом.
- Лучше брать из витрины финпредложений: в `js/config.js` → `source: 'https://витрина/data.php?cat=hr'`.
  Тогда вакансии правятся в телеграм-боте витрины и сразу появляются здесь.

## Заявки

Форма шлёт в `send.php`: проверка полей, ловушка для ботов, не больше 3 заявок за 10 минут
с одного адреса, копия в CSV (`.smena-private/leads.csv` над корнем сайта) и сообщение в Telegram.
Настройка: `send-config.sample.php` → `send-config.php`, вписать `token` бота и `chat_ids`
(свой id — у @userinfobot; получатель должен хоть раз нажать «Старт» у бота).

## Перед запуском

- Название и реквизиты (ИНН/ОГРН/адрес) — в подвале и в `privacy.html`. Без них «серьёзной конторы» не выйдет.
- Ник Telegram — `js/config.js` → `telegram`.
- Условия вакансий в стартовых данных — пример, заменить на реальные из партнёрки.
- Отзывы и цифры «мы трудоустроили N человек» не добавлять, пока нет настоящих.
